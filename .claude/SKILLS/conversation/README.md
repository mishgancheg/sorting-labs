# Папка conversation: скилл общения с пользователем

Универсальный скилл для любых проектов и любых агентов (Claude Code, Codex и другие). Учит агента общаться понятным языком и подавать суть без воды. Скилл не привязан ни к одному инструменту: это обычные текстовые файлы с инструкциями, которые подключаются в любой агент, читающий файлы настроек перед работой.

## Состав

- `SKILL.md` — главный скилл: портрет читателя, определение цели текста, правило 80 на 20, требования к языку. Подключается всегда.
- `explain/SKILL.md` — сценарий «объясни»: концепции, термины, код, ошибки.
- `plan/SKILL.md` — сценарий «составь план»: планы работ и предложения о порядке действий.
- `report/SKILL.md` — сценарий «проверь работу»: итоги и помощь в проверке.
- `choice/SKILL.md` — сценарий «предложи варианты»: выбор между путями решения.
- `document/SKILL.md` — сценарий «подготовь документ»: руководства, методички, инструкции.

Главный скилл самодостаточен, дочерние его уточняют. Агент открывает дочерний файл перед соответствующей задачей.

## Подключение в Claude Code (один проект)

1. Скопируй папку `conversation` в корень нужного проекта.
2. В корне проекта создай или открой файл `CLAUDE.md` и добавь в него одну строку:

   ```
   @conversation/SKILL.md
   ```

   Запись вида «символ @ и путь» — это встроенный в Claude Code механизм подключения файлов: содержимое указанного файла загружается в каждый сеанс автоматически. После этого правила общения применяются сами, без напоминаний и без вызова скилла командой.

## Подключение в Claude Code (все проекты сразу)

Добавь строку в глобальный файл настроек `C:\Users\user\.claude\CLAUDE.md`:

```
@C:/M/Obsidian/Сортировки/conversation/SKILL.md
```

Путь здесь абсолютный, поэтому копировать папку в каждый проект не нужно. Правила начнут действовать во всех проектах на этой машине.

## Подключение в Codex

Codex перед работой читает файл `AGENTS.md` из корня проекта, но подключать другие файлы по ссылке не умеет. Поэтому действует так:

1. Скопируй папку `conversation` в корень проекта.
2. В файле `AGENTS.md` (создай, если его нет) размести текст главного `conversation/SKILL.md` целиком и добавь строку: «Перед задачами на объяснение, составление планов, итоги работы, выбор вариантов и подготовку документов сначала читай соответствующий файл в папке conversation».

В Codex есть и глобальные инструкции — файл `AGENTS.md` в папке `~/.codex` внутри домашней папки пользователя. Приём тот же самый: вставить туда текст главного скилла.

## Другие агенты

Принцип один для всех: у агента есть файл, который он читает перед работой (CLAUDE.md, AGENTS.md, GEMINI.md, .cursorrules). Главный скилл помещается туда — целиком, если ссылки не поддерживаются, или строкой подключения, если поддерживаются.
