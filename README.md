## Назначение

Фреймворк объединяет три части:

1. **Алгоритмы** (`src/sorting_lab/algorithms/`) — реализации сортировок
   из научных статей, по одному модулю на алгоритм. Каждый модуль несёт
   «паспорт»: статью-источник, оценки сложности, устойчивость, работу на месте.
2. **Наборы данных** (`src/sorting_lab/datasets/`) — параметрические
   генераторы входов с воспроизводимым случайным зерном и эталонные крайние
   случаи для проверки корректности.
3. **Измерительный стенд** (`src/sorting_lab/bench/`) — компараторы-счётчики
   и метрики прогона (число сравнений, время), расширяемые по мере надобности.

Научные статьи, по которым пишутся реализации, лежат в каталоге `papers/`.

## Установка

Требуется Python 3.12 или новее. Из корня проекта:

```
.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

Команда установит пакет в режиме разработки (изменения кода видны сразу,
переустановка не нужна) вместе с зависимостями: numpy, matplotlib и pytest.

## Запуск тестов

```
.venv\Scripts\python.exe -m pytest
```

Тесты проверяют корректность всех реализованных алгоритмов на эталонных
случаях и генераторах, а также воспроизводимость наборов данных.

## Добавление нового алгоритма

1. Создайте файл `src/sorting_lab/algorithms/<имя>.py` по образцу
   `heapsort.py` (полностью реализованный эталон стиля) или любой заготовки
   (`introsort.py` и другие): класс-наследник `Algorithm` с паспортом
   `AlgorithmInfo` и методом `sort(data, compare)`.
2. Импортируйте класс и зарегистрируйте экземпляр в
   `src/sorting_lab/algorithms/__init__.py`.

После этого алгоритм автоматически участвует в тестах корректности и доступен
измерительному стенду через `sorting_lab.REGISTRY`.

## Структура проекта

```
src/sorting_lab/        код фреймворка (пакет)
  algorithms/           реализации сортировок
  datasets/             генераторы данных и крайние случаи
  bench/                метрики измерительного стенда
  base.py               базовый класс алгоритма и контракт компаратора
  registry.py           реестр алгоритмов
tests/                  тесты pytest
papers/                 научные статьи (архив источников)
claudedocs/             аналитические документы и отчёты
```
